# Approved surface brief

Reference: A · Outline, selected by the user before execution. Bind the build to flat offwhite `#f7f7f5`, ink `#202522`, green `#315c48`, macOS system sans 12–13 px, fine separators and 4–6 px control corners. Content dominates; no cards, hero, gradients, glass or decorative art.

Confirmed refinement overrides the mock’s always-visible tree: **Auto default** is one Organize tabs action and honest progress, then Undo / quiet Keep this order; **Advanced** adds guided Read / Review / Apply and the Outline title/domain hierarchy. Current native group stays visible. Auto action/progress stays beside the target with no forced empty page; reuse one action slot through Cancel (proposal only), disabled Applying and Undo. Advanced uses one contextual primary, status above the tree, compact secondary controls and a footer that cannot cover important status. No new image-selection round is needed. Mock favicon/menu embellishments are unsupported and must not be implemented. Generic document SVGs are local and private.

Safety belongs to both modes: one immutable-config controller path, no duplicate operations or scope/mode changes during work, no AI transmission without valid settings/permission, no-change means no Apply, no native cancellation or timeout replay. Recovery actions use native inspection data and explicit consequence confirmation. Full tokens are in [DESIGN.md](../DESIGN.md) and [design.json](design.json).
